# Личная страница — Руслан Рощупкин

Статический CV-сайт: дополнение или замена PDF-резюме. Без зависимостей и
build-шага — три файла + PDF.

```
personal-site/
  index.html      разметка и секции
  styles.css      светлая тема + тёмная (переключатель), адаптив
  script.js       переключатель языка RU/EN и темы (localStorage)
  Ruslan_CV.pdf   резюме для кнопки «Скачать»
```

## Локальный запуск

Можно просто открыть `index.html` в браузере. Чтобы `localStorage` и загрузка PDF
работали как в проде, лучше через локальный сервер:

```bash
cd personal-site
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Деплой

Сайт развёрнут на GitHub Pages: **https://rroshchupkinn.github.io**

Репозиторий — `rroshchupkinn/rroshchupkinn.github.io`, ветка `main`, папка `/ (root)`.
Эта папка (`personal-site/`) — локальная рабочая копия с тем же `origin`.

Чтобы выкатить изменения, из папки `personal-site/`:

```bash
git add .
git commit -m "update content"
git push
```

Pages пересоберётся автоматически за ~1 минуту.

## Обновление контента

Сайт — живой документ: раз в 3–6 месяцев стоит обновлять кейсы и метрики.

- Тексты на двух языках лежат в `script.js` в объекте `I18N` (`ru` и `en`).
  Значения по умолчанию в `index.html` — русские; при правке меняйте оба места,
  чтобы языки не разъезжались.
- Новый кейс: скопировать блок `<article class="case">` в `index.html` и добавить
  соответствующие ключи `c5_*` в `I18N.ru` и `I18N.en`.
- Заменить резюме: положить новый файл как `Ruslan_CV.pdf`.
